# OpenRouter 免费模型看板

实时展示 OpenRouter 平台上所有免费 AI 模型的监控看板。按真实价格字段筛选零成本模型，支持匿名、预览、路由、多模态等分类筛选。

## 功能

- 🔄 实时拉取 OpenRouter 模型列表
- 🆓 筛选所有输入/输出价格均为 $0 的模型
- 🔍 按名称、ID 搜索
- 🏷️ 匿名/预览/路由/视觉/音频 分类
- 📊 卡片 / 表格 双视图

## 技术栈

纯静态 HTML + CSS + Vanilla JS，无需任何构建工具。

## 部署

### Cloudflare Pages

1. Fork 本仓库
2. 在 Cloudflare Pages 中连接 GitHub
3. 输出目录留空（根目录），无需构建命令
4. 部署即可

或直接拖拽 `index.html` 到 Cloudflare Pages 的 Upload Assets。
